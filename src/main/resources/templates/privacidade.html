Política de privacidade

Última atualização: 30/10/2026

O GymSync é um trabalho acadêmico (Análise e Desenvolvimento de Sistemas). A versão publicada usa dados de exemplo. Esta política descreve como o sistema trata dados pessoais quando usado por uma academia, seguindo a Lei Geral de Proteção de Dados (Lei 13.709/2018).

1. Quais dados o GymSync guarda

  • Cadastro: nome, CPF, e-mail, telefone e data de nascimento (do professor, também a especialidade), além da data em que o aluno aceitou esta política.
  • Plano e pagamentos: matrícula, plano, mensalidades (valor, vencimento, situação e data do pagamento). O Pix é simulado: o sistema não recebe dados bancários.
  • Frequência: data e hora de cada passagem pela catraca.
  • Treino: fichas montadas pelo professor, exercícios marcados como feitos (com carga) e reservas de aulas coletivas.
  • Avaliações físicas: peso, altura, percentual de gordura e medidas. São dados de saúde (dados sensíveis na LGPD) e só o aluno, os professores e a administração da academia os veem.
  • Mensagens trocadas entre aluno e professor dentro do sistema.
  • Histórico de ações: o sistema registra quem fez cada alteração (nome, perfil, data e hora e uma descrição), para a administração poder conferir.
  • Segurança: a senha é guardada só de forma criptografada (BCrypt); tentativas de login erradas ficam na memória do servidor por 15 minutos, para bloquear ataques.

2. Para que os dados são usados

  • Cumprir o contrato com a academia: matrícula, cobrança das mensalidades e liberação da catraca.
  • Acompanhar o treino e a evolução física, com o consentimento do aluno, dado no primeiro acesso.
  • Avisar o aluno de mensalidades perto do vencimento e o professor de alunos que pararam de vir.
  • Gerar relatórios internos da academia (frequência e faturamento).

Os dados não são vendidos nem usados para propaganda.

3. Com quem os dados são compartilhados

  • Hospedagem: o site publicado roda no Render e o banco de dados na Aiven (servidores nos Estados Unidos).
  • E-mail: só quando a ficha de treino é enviada por e-mail (pelo aluno ou pelo professor) ou quando alguém pede a recuperação de senha, o endereço e a mensagem passam pelo provedor de envio (Brevo ou Gmail).
  • Fonte das letras: as páginas carregam a fonte Outfit do Google Fonts, então o Google recebe o endereço IP do seu aparelho ao abrir o sistema.
  • WhatsApp: os botões de WhatsApp só abrem o aplicativo no seu aparelho com o texto pronto; nada é enviado sem você confirmar.

4. Por quanto tempo

Enquanto o aluno tiver vínculo com a academia. Depois, os dados de cobrança podem ser mantidos pelo prazo exigido por lei; os demais podem ser excluídos a pedido. A exclusão de um aluno no sistema apaga junto as matrículas, mensalidades, entradas, fichas, avaliações, reservas de aula e mensagens dele. O histórico de ações não é apagado junto.

5. Seus direitos

Pela LGPD (art. 18), você pode:

  • Acessar e levar seus dados: na Minha Área, use Baixar meus dados para receber um arquivo com tudo o que o sistema guarda sobre você.
  • Corrigir dados errados ou desatualizados.
  • Pedir a exclusão dos dados ou revogar o consentimento das avaliações físicas.
  • Saber com quem os dados foram compartilhados.

Para correção, exclusão ou dúvidas, fale com a recepção da academia ou escreva para suportegymsync@gmail.com.

6. Cookies e armazenamento no navegador

O GymSync usa apenas o cookie de sessão, necessário para manter o login, e guarda no seu navegador preferências como o tema claro ou escuro e, se você instalar o app no celular, arquivos visuais para ele abrir sem internet (sem dados pessoais). Não há cookies de propaganda nem de rastreamento. O vídeo de apresentação do YouTube só é carregado se você clicar para assistir.

7. Segurança

Acesso separado por perfil (aluno, professor e administração), senhas criptografadas, conexão HTTPS no site publicado, bloqueio após tentativas de login erradas e histórico das ações feitas no sistema.
